## Validated on real compute

- **Eval, Tinker, untrained Qwen3.5-4B.** AIME25 and HMMT25, n=30, G=1,
  32k-token budget, 7 protocols ($14, plus a $2.60 multi-session rerun).
  - No agent system beats `single`.
  - Parallel protocols lose at matched compute: splitting a 32k budget
    truncates every peer's chain.
  - Coordinator and notes-to-self tie `single` on AIME25 while using about 60%
    of its tokens.
  - All results are [pilot]. See the wiki synthesis
    `syntheses/agent-systems-vs-single-matched-compute.md`.
- **RL, Tinker** ($0.42).
  - 3-step smokes: coordinator with shared vs per-role LoRA, and
    multi-session with credit on all vs last.
  - `kl_sample_train` was 2e-4 to 1e-3.
- **RL, local, H100** (M4 pilot; `experiments/2026-09-24_local-learner-pilot/`).
  - Per-role LoRA, 20 steps × 32 episodes.
  - IS ratio ≈ 1 per adapter (±4e-4), KL ~4e-4, every hot-load verified.
  - Kill + resume works.
  - About 1.5 minutes per step with the model co-located on one GPU.

## Not yet validated / deferred

- **Code eval or RL on real models.** The `code_fn` env is reviewed and
  hardened (grading follows LiveCodeBench semantics), but no model has been
  run on it yet. The first LCB v6 eval is the next paid step.
- **Docker sandbox on real Docker.** It is only tested against a fake
  `docker`. Run `MARLI_TEST_DOCKER=1 uv run --extra dev pytest -m docker` on a
  laptop or AWS box first.
- **`swe` env** (repo-level SWE). Not started; it needs Docker.
- **gpt-oss local training.** Expert LoRA is not at parity in vLLM (about 6%
  over-application). Attention-only LoRA is the default.
- **HF persistence.** Everything is on local `/workspace` for now, at Sid's
  request. Artifacts go to HF once the private space exists.

## Suggested next experiments (each needs a cost confirmation)

1. **Finish the HMMT25 multi-session rerun** (~$2, Tinker). It completes the
   baseline table.
2. **Budget sweep for the baselines:** 16k / 32k / 64k episode budgets, G=2,
   same cells, AIME25 + HMMT25 (~$100, Tinker; the 32k G=1 pilot cost $14). This is the plan's
   "accuracy vs compute at ≥3 budget levels". It tests whether parallel
   protocols recover once each peer's budget fits a chain. Include a debate
   variant whose per-round cap fits a thinking model.
3. **First training comparison** on the local backend. Coordinator, shared vs
   per-role LoRA, POLARIS, ~100 steps × 32 episodes each, evaluated on AIME25
   and HMMT25 before and after. About 2.5 h per arm on one H100, roughly $9 per
   arm plus eval. Lower the learning rate from 1e-5 only if grad norms blow up.
   Watch zero-variance groups: 4.6/8 per step at G=4. G=8 would help.
4. **Multi-session credit: last vs all sessions.** Same setup with
   `multi_session_s3_notes` (the plan's gap in the literature).
5. **LCB v6 code eval:** single / multi-session / coordinator on Qwen3.5-4B,
   Tinker, 131 tasks, ~$10.
